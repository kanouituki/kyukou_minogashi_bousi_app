## 回答例

### Q1: 実際の動作デモについて
**A:** 今回はngrok経由でのAPI接続のため、リアルタイムデモが困難でした。しかし基本機能（位置記録、API連携、休講情報表示）は全て動作確認済みです。Unity上での画面遷移とサーバーからの実際のレスポンスデータをお見せできます。

### Q2: 処理速度とサーバー負荷について
**A:** 現在の処理時間は全コース分析で約15-30秒です。実装済みのキャッシュ機能により、2回目以降は数秒で応答できます。DDoS対策として、APIレート制限とキャッシュ活用により負荷を最小限に抑えています。

### Q3: Canvas APIでの課題情報取得について
**A:** Canvas APIでは課題情報も取得可能です。現在は休講情報に特化していますが、同じ仕組みで課題期限通知や教授別課題傾向分析も技術的に実現可能です。

### Q4: 自動実行・SNS通知機能について
**A:** 現在は手動取得ですが、cron等での定期実行は既に想定済みです。Twitter API、LINE Bot APIとの連携も技術的には可能で、今後の拡張として検討しています。

### Q5: システムの正確性について
**A:** GPT-4による自然言語解析を使用しており、テストでは高い精度で休講情報を判定できています。ただし、曖昧な表現や特殊なケースでは誤判定の可能性もあるため、継続的な改善が必要です。

### Q6: スマートフォン対応について
**A:** Unity製のため、Android/iOS対応は技術的には可能です。今回はngrokを使用したため実機デモが困難でしたが、適切なサーバー環境があればモバイルアプリとして配布可能です。
